# 仕様書: データ入力画面

## 目的

現場保全担当者が自由記述の故障報告テキストを入力し、LLMによって構造化データ（JSON）に変換・確認・保存する画面。
故障報告の「入口」として、非構造化データを分析可能な構造化データに変換する役割を担う。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | テキスト入力 | 自由記述の故障報告テキストを入力する |
| 2 | LLM構造化 | 入力テキストをLLM APIに送信し、構造化JSONを生成する |
| 3 | 構造化結果表示 | LLMが抽出した構造化データ（現象・原因・対策・コスト・停止時間等）を表示する |
| 4 | 構造化結果の編集 | 構造化結果を人間が確認・修正できる |
| 5 | データ保存 | 確認済みの構造化データをDBに保存する |
| 6 | サンプルデータ投入 | デモ用のサンプル故障報告テキストを一括で投入し構造化する |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| テキストエリア | 故障報告の自由記述を入力する大きなテキスト入力欄 | メインエリア上部 |
| 構造化ボタン | LLM APIを呼び出して構造化処理を実行する | テキストエリア下 |
| ローディング表示 | LLM処理中のスピナー/プログレス表示 | 構造化ボタン付近 |
| 構造化結果カード | 抽出された各項目（発生日、設備名、現象、原因、対策、コスト、停止時間、故障モード）を表示 | メインエリア下部 |
| 編集フォーム | 構造化結果の各項目を修正できる入力フィールド群 | 結果カード内 |
| 保存ボタン | 確認済みデータをDBに保存する | 結果カード下部 |
| サンプル投入ボタン | デモ用サンプルデータを一括投入する | ヘッダーまたはサイドバー |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| テキスト入力 | テキストエリア | ユーザーが故障報告テキストを自由記述で入力する |
| LLM構造化 | 構造化ボタン → ローディング表示 | ボタンクリックでLLM APIを呼び出し、処理中はローディング表示 |
| 構造化結果表示 | 構造化結果カード | LLM処理完了後、抽出された各項目がカード形式で表示される |
| 構造化結果の編集 | 編集フォーム | 各項目をクリックして編集モードに切り替え、値を修正する |
| データ保存 | 保存ボタン | クリックで構造化データをDBに保存、成功通知を表示 |
| サンプルデータ投入 | サンプル投入ボタン | クリックで複数のサンプルデータを自動構造化・保存 |
