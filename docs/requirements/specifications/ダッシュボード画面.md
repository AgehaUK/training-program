# 仕様書: ダッシュボード画面

## 目的

構造化済みの故障データを集計・可視化し、故障傾向・コスト・トレンドを一目で把握できるようにする画面。
設備設計者が設計改善の根拠を得たり、工場管理者が投資判断を行うための分析基盤となる。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | 故障モード別内訳表示 | 故障モード（劣化、破損、動作不良等）の発生件数を円グラフで表示する |
| 2 | 月次トレンド表示 | 月別の故障発生件数の推移を折れ線グラフで表示する |
| 3 | コストTOP10表示 | 故障コストが高い設備・部品のランキングを棒グラフで表示する |
| 4 | 示唆出し | 分析結果からLLMが改善施策の示唆を自動生成し表示する |
| 5 | フィルタリング | 期間・設備名・故障モード等でデータを絞り込む |
| 6 | サマリー統計 | 総故障件数、総コスト、平均停止時間等のKPIを表示する |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| KPIカード群 | 総故障件数・総コスト・平均停止時間等のサマリー数値 | 画面上部 |
| 円グラフ | 故障モード別の発生件数内訳 | メインエリア左上 |
| 折れ線グラフ | 月次の故障発生件数トレンド | メインエリア右上 |
| 棒グラフ | コストTOP10の設備・部品ランキング | メインエリア左下 |
| 示唆カード | LLMが生成した改善施策の示唆テキスト | メインエリア右下 |
| フィルターバー | 期間選択・設備名・故障モードのドロップダウン/入力 | 画面上部（KPIカードの上） |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| 故障モード別内訳表示 | 円グラフ | 構造化データを集計し、故障モード別の割合を円グラフで描画 |
| 月次トレンド表示 | 折れ線グラフ | 月別に故障件数を集計し、時系列の推移を折れ線グラフで描画 |
| コストTOP10表示 | 棒グラフ | コスト降順で上位10件を集計し、棒グラフで描画 |
| 示唆出し | 示唆カード | 集計結果をLLM APIに送信し、改善施策の示唆テキストを生成・表示 |
| フィルタリング | フィルターバー | フィルター条件変更時に全グラフ・KPIを再描画 |
| サマリー統計 | KPIカード群 | 構造化データ全体から主要KPIを算出し、カードに表示 |
