# 仕様書: 検索画面

## 目的

過去の故障事例をキーワードで検索し、類似事例の一覧を表示する画面。
現場保全担当者が故障発生時に迅速に過去事例を参照したり、設備設計者が特定部品の故障履歴を調査するために使用する。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | キーワード検索 | 設備名・部品名・現象等のキーワードで故障事例を検索する |
| 2 | 検索結果一覧表示 | 検索条件に合致する故障事例をリスト形式で表示する |
| 3 | 詳細表示 | 一覧から選択した故障事例の構造化データ全項目を表示する |
| 4 | 絞り込みフィルタ | 期間・故障モード・コスト範囲等で検索結果を絞り込む |
| 5 | ソート | 発生日・コスト・停止時間等で検索結果を並び替える |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| 検索ボックス | キーワードを入力するテキストフィールド | 画面上部中央 |
| 検索ボタン | 検索を実行するボタン | 検索ボックス右 |
| フィルターパネル | 期間・故障モード・コスト範囲等の絞り込み条件 | 検索ボックス下部 |
| 検索結果テーブル | 故障事例の一覧（発生日、設備名、現象、原因、コスト、停止時間） | メインエリア |
| ソートボタン群 | テーブルヘッダーのソート切り替え | テーブルヘッダー |
| 詳細モーダル/パネル | 選択した事例の全項目を表示するモーダルまたはサイドパネル | オーバーレイ/右サイド |
| 件数表示 | 検索結果の総件数を表示 | テーブル上部 |
| ページネーション | 検索結果のページ切り替え | テーブル下部 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| キーワード検索 | 検索ボックス → 検索ボタン | キーワード入力後、ボタンクリックまたはEnterで検索実行 |
| 検索結果一覧表示 | 検索結果テーブル、件数表示 | 検索結果を一覧表示、件数をテーブル上部に表示 |
| 詳細表示 | 検索結果テーブルの行 → 詳細モーダル/パネル | テーブル行クリックで詳細を表示 |
| 絞り込みフィルタ | フィルターパネル | フィルター条件変更時に検索結果を再取得・再表示 |
| ソート | ソートボタン群 | テーブルヘッダークリックで昇順/降順を切り替え |
