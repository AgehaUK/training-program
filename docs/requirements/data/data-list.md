# Data 一覧

> 必要なデータ項目の一覧

## データ項目一覧

### 故障レコード（コアデータ）

| # | データ名 | 説明 | 関連機能 | データ型 | 必須 |
|---|---------|------|---------|---------|------|
| 1 | レコードID | 故障レコードの一意識別子（自動採番） | 全機能 | INTEGER (PK) | Yes |
| 2 | 元テキスト | ユーザーが入力した自由記述の故障報告テキスト | テキスト入力, LLM構造化, 詳細表示 | TEXT | Yes |
| 3 | 発生日 | 故障が発生した日付 | LLM構造化, 月次トレンド, 検索, ソート, フィルタ | DATE | Yes |
| 4 | 設備名 | 故障が発生した設備の名称 | LLM構造化, コストTOP10, 検索, フィルタ | VARCHAR | Yes |
| 5 | 現象 | 故障の現象・症状の説明 | LLM構造化, 検索結果一覧, 検索, 詳細表示 | TEXT | Yes |
| 6 | 原因 | 故障の原因 | LLM構造化, 検索結果一覧, 検索, 詳細表示 | TEXT | No |
| 7 | 対策 | 実施した対策・修理内容 | LLM構造化, 検索, 詳細表示 | TEXT | No |
| 8 | コスト | 故障対応にかかった費用（円） | LLM構造化, コストTOP10, サマリー統計, ソート, フィルタ | INTEGER | No |
| 9 | 停止時間 | 設備の停止時間（時間単位） | LLM構造化, サマリー統計, ソート | FLOAT | No |
| 10 | 故障モード | 故障の分類（劣化, 破損, 動作不良, 漏れ, 過熱 等） | LLM構造化, 故障モード別内訳, フィルタ | VARCHAR | Yes |

### メタデータ

| # | データ名 | 説明 | 関連機能 | データ型 | 必須 |
|---|---------|------|---------|---------|------|
| 11 | 登録日時 | レコードがDBに保存された日時（自動記録） | データ保存 | DATETIME | Yes |
| 12 | データソース | データの投入元（manual: 手動入力, sample: サンプル投入） | データ保存, サンプルデータ投入 | VARCHAR | Yes |

### 集計・分析データ（非永続、画面表示用）

| # | データ名 | 説明 | 関連機能 | データ型 | 必須 |
|---|---------|------|---------|---------|------|
| 13 | 総故障件数 | フィルタ対象期間内の故障レコード総数 | サマリー統計 | INTEGER | - |
| 14 | 総コスト | フィルタ対象期間内のコスト合計 | サマリー統計 | INTEGER | - |
| 15 | 平均停止時間 | フィルタ対象期間内の停止時間の平均 | サマリー統計 | FLOAT | - |
| 16 | 故障モード別件数 | 故障モードごとの発生件数 | 故障モード別内訳表示 | MAP(VARCHAR → INTEGER) | - |
| 17 | 月別故障件数 | 月ごとの故障発生件数 | 月次トレンド表示 | MAP(DATE → INTEGER) | - |
| 18 | 設備別コスト合計 | 設備/部品ごとのコスト合計（TOP10用） | コストTOP10表示 | MAP(VARCHAR → INTEGER) | - |
| 19 | 示唆テキスト | LLMが生成した改善施策の示唆 | 示唆出し | TEXT | - |

### フィルタ・検索条件（ユーザー入力、非永続）

| # | データ名 | 説明 | 関連機能 | データ型 | 必須 |
|---|---------|------|---------|---------|------|
| 20 | 検索キーワード | ユーザーが入力した検索文字列 | キーワード検索 | VARCHAR | - |
| 21 | フィルタ期間（開始） | 絞り込みの開始日 | フィルタリング, 絞り込みフィルタ | DATE | - |
| 22 | フィルタ期間（終了） | 絞り込みの終了日 | フィルタリング, 絞り込みフィルタ | DATE | - |
| 23 | フィルタ設備名 | 絞り込み対象の設備名 | フィルタリング | VARCHAR | - |
| 24 | フィルタ故障モード | 絞り込み対象の故障モード | フィルタリング, 絞り込みフィルタ | VARCHAR | - |
| 25 | フィルタコスト範囲 | 絞り込み対象のコスト範囲（min-max） | 絞り込みフィルタ | INTEGER×2 | - |
| 26 | ソートカラム | ソート対象のカラム名 | ソート | VARCHAR | - |
| 27 | ソート方向 | 昇順/降順 | ソート | VARCHAR(ASC/DESC) | - |

## データ項目の分類

| 分類 | 項目数 | 永続化 | 説明 |
|------|--------|--------|------|
| 故障レコード（コアデータ） | 10項目 | DB保存 | LLMが構造化した故障情報の本体 |
| メタデータ | 2項目 | DB保存 | レコード管理用の付帯情報 |
| 集計・分析データ | 7項目 | 非永続（算出値） | ダッシュボード表示用の集計結果 |
| フィルタ・検索条件 | 8項目 | 非永続（UI状態） | ユーザー操作による絞り込み条件 |
