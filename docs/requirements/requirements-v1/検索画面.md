# 要件定義書: 検索画面

## 目的

過去の故障事例をキーワードで検索し、類似事例の一覧を表示する画面。
現場保全担当者が故障発生時に迅速に過去事例を参照したり、設備設計者が特定部品の故障履歴を調査するために使用する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | キーワード検索 | 設備名・部品名・現象等のキーワードで故障事例を検索する | 新規 |
| 2 | 検索結果一覧表示 | 検索条件に合致する故障事例をリスト形式で表示する | 新規 |
| 3 | 詳細表示 | 一覧から選択した故障事例の構造化データ全項目を表示する | 新規 |
| 4 | 絞り込みフィルタ | 期間・故障モード・コスト範囲等で検索結果を絞り込む | 新規 |
| 5 | ソート | 発生日・コスト・停止時間等で検索結果を並び替える | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| キーワード検索 | ユーザーが入力したキーワード（例:「温度センサー」） | DBの構造化データに対してLIKE検索（設備名、現象、原因、対策の各フィールド） | マッチした故障レコード一覧 |
| 検索結果一覧表示 | 検索結果の故障レコード群 | レコードをテーブル行としてレンダリング（発生日, 設備名, 現象, 原因, コスト, 停止時間） | テーブル表示、件数表示 |
| 詳細表示 | ユーザーが選択した故障レコードのID | IDでDBから全項目を取得 | モーダル/パネルに全項目（発生日, 設備名, 現象, 原因, 対策, コスト, 停止時間, 故障モード, 元テキスト）を表示 |
| 絞り込みフィルタ | ユーザーが選択した期間・故障モード・コスト範囲 | フィルタ条件を検索クエリに追加し、DBを再クエリ | フィルタ適用後の検索結果一覧 |
| ソート | ユーザーが選択したソートカラムと方向（昇順/降順） | 検索結果をORDER BYで並び替え | ソート適用後の検索結果一覧 |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| 検索ボックス | キーワード検索 | 空（初期、プレースホルダ表示）→ 入力中 → 入力済み |
| 検索ボタン | キーワード検索 | 無効（検索ボックス空）→ 有効（入力あり）→ ローディング（検索中）→ 有効（完了） |
| 検索結果テーブル | 検索結果一覧表示 | 非表示（初期）→ ローディング（検索中）→ 結果表示 → 空結果表示（0件時） |
| フィルターパネル | 絞り込みフィルタ | 折りたたみ（初期）→ 展開（ユーザー操作）→ フィルタ適用中 |
| ソートボタン群 | ソート | 未選択（初期）→ 昇順（1回クリック）→ 降順（2回クリック） |
| 詳細モーダル/パネル | 詳細表示 | 非表示（初期）→ 表示（行クリック時）→ 非表示（閉じる操作） |
| 件数表示 | 検索結果一覧表示 | 非表示（初期）→ 「N件の結果」表示 |
| ページネーション | 検索結果一覧表示 | 非表示（結果1ページ以内）→ 表示（複数ページ時、現在ページをハイライト） |
