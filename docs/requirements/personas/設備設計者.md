# ペルソナ: 設備設計者

## ユーザー属性

| 項目 | 内容 |
|------|------|
| 名前 | 田中 慎一 |
| 年齢 | 40代 |
| 職業 | 設備設計エンジニア |
| 部門 | 設計部 |
| 勤務地 | 本社（設計拠点） |
| 技術スキル | CAD・設計ツールに精通。データ分析ツールの利用経験は少ない |

## 目標・ゴール

- 故障しにくい設備を設計し、工場の稼働率を向上させたい
- 過去の故障データから設計上の弱点を把握し、次世代設備に反映したい
- 設計段階で「壊れやすい箇所」を事前に特定し、耐久性を改善したい

## 課題

- 保全記録が自由記述で構造化されておらず、設計に活かせる形で参照できない
- 現場からのフィードバックが口頭ベースで、体系的に蓄積されていない
- どの部品・どの箇所が頻繁に故障しているか、定量的に把握する手段がない
- 現場に出向く時間が限られ、設計と保全の間に情報ギャップがある

**心情**: 「現場で何が壊れているか知りたいが、膨大な自由記述を読む時間はない。グラフや数字で傾向が見えれば、設計に活かせるのに。」

## 利用状況

| 利用場面 | 頻度 | 詳細 |
|---------|------|------|
| 新規設備の設計時 | 月1〜2回 | ダッシュボードで故障傾向を確認し、弱点箇所を設計で改善 |
| 設計レビュー準備 | 月1回 | コストTOP10・故障モード別分析を資料として活用 |
| 類似設備の故障調査 | 随時 | 検索画面で特定部品・設備の過去事例を調査 |
