# ペルソナ: 工場管理者

## ユーザー属性

| 項目 | 内容 |
|------|------|
| 名前 | 山本 雅人 |
| 年齢 | 50代 |
| 職業 | 工場長 |
| 部門 | 工場管理部 |
| 勤務地 | 工場事務所 |
| 技術スキル | 経営・管理視点が中心。Excel・BIツールは閲覧レベルで使用 |

## 目標・ゴール

- 故障によるコスト・停止時間を削減し、工場全体の稼働率を向上させたい
- データに基づいて保全投資の優先度を判断し、限られた予算を最適配分したい
- 経営層への報告資料を、定量データに基づいて迅速に作成したい

## 課題

- 故障コストの全体像が把握できず、投資判断が経験と勘に頼っている
- 月次報告のデータ集計に手作業が多く、時間がかかる
- どの設備・どの故障モードに優先的に投資すべきか、データで示せない
- 改善施策の効果を定量的に追跡する仕組みがない

**心情**: 「年間数千万円の保全コストがかかっているが、どこに手を打てば効果的なのか、データで判断したい。」

## 利用状況

| 利用場面 | 頻度 | 詳細 |
|---------|------|------|
| 月次経営報告の準備 | 月1回 | ダッシュボードのコストTOP10・トレンドを確認・出力 |
| 保全投資の意思決定 | 四半期1回 | 故障モード別分析と示唆から投資優先度を判断 |
| 異常値の確認 | 随時 | 突発的なコスト増や停止時間増をダッシュボードで検知 |
