# ペルソナ: 現場保全担当者

## ユーザー属性

| 項目 | 内容 |
|------|------|
| 名前 | 佐藤 健太 |
| 年齢 | 30代 |
| 職業 | 保全技術者 |
| 部門 | 保全部 |
| 勤務地 | 工場現場 |
| 技術スキル | 設備の点検・修理に精通。PCは基本操作レベル、Webアプリは日常的に使用 |

## 目標・ゴール

- 故障発生時に過去の類似事例を素早く見つけ、復旧時間を短縮したい
- 故障報告を効率的に記録し、後から活用できる形で残したい
- 経験の浅いメンバーでも過去事例を参照して対応できるようにしたい

## 課題

- 過去の故障事例を探すのに時間がかかる（Oracle DBを直接検索する手段がない）
- ベテランの経験・知識が属人化しており、引き継ぎが困難
- 自由記述で書いた報告書が後から検索・分析に使えない
- 似たような故障が繰り返されているが、傾向を俯瞰できない

**心情**: 「前にも同じ故障があったはず。あのとき誰がどう直したか、すぐ見つかればいいのに。」

## 利用状況

| 利用場面 | 頻度 | 詳細 |
|---------|------|------|
| 故障発生時の事例検索 | 週2〜3回 | 検索画面で類似故障の対処法を確認 |
| 故障報告の入力 | 日次 | データ入力画面で自由記述テキストを構造化 |
| 月次の故障振り返り | 月1回 | ダッシュボードで自担当エリアの故障傾向を確認 |
