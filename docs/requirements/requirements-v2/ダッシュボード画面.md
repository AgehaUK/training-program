# 要件定義書 v2: ダッシュボード画面

> DB設計を踏まえた要件定義書の更新

## 目的

構造化済みの故障データを集計・可視化し、故障傾向・コスト・トレンドを一目で把握できるようにする画面。
設備設計者が設計改善の根拠を得たり、工場管理者が投資判断を行うための分析基盤となる。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | 故障モード別内訳表示 | 故障モード別の発生件数を円グラフで表示 | DB関連テーブル: failure_reports JOIN failure_modes |
| 2 | 月次トレンド表示 | 月別の故障発生件数の推移を折れ線グラフで表示 | DB関連テーブル: failure_reports |
| 3 | コストTOP10表示 | コストが高い設備のランキングを棒グラフで表示 | DB関連テーブル: failure_reports |
| 4 | 示唆出し | 分析結果からLLMが改善施策の示唆を自動生成 | DB関連テーブル: failure_reports JOIN failure_modes（集計データをLLMに送信） |
| 5 | フィルタリング | 期間・設備名・故障モード等でデータを絞り込む | DB関連テーブル: failure_reports, failure_modes |
| 6 | サマリー統計 | 総故障件数、総コスト、平均停止時間のKPI表示 | DB関連テーブル: failure_reports |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| 故障モード別内訳表示 | フィルタ条件（または全件） | failure_reports と failure_modes をJOINし、故障モード別にCOUNT | 円グラフ（モード名: 件数） | failure_reports（READ）, failure_modes（READ, JOIN） |
| 月次トレンド表示 | フィルタ条件（または全件） | failure_reports.occurred_at を月単位でGROUP BY、COUNT | 折れ線グラフ（月: 件数） | failure_reports（READ） |
| コストTOP10表示 | フィルタ条件（または全件） | failure_reports.equipment_name でGROUP BY、cost をSUM、降順TOP10 | 棒グラフ（設備名: コスト合計） | failure_reports（READ） |
| 示唆出し | 集計済み分析結果 | 故障モード内訳・トレンド・コストTOP10をLLM APIに送信し示唆生成 | 示唆テキスト | failure_reports（READ）, failure_modes（READ） |
| フィルタリング | ユーザー選択（期間, 設備名, 故障モード） | WHERE句を構築しfailure_reportsを再クエリ。故障モード選択肢はfailure_modesから取得 | 全グラフ・KPI再描画 | failure_reports（READ）, failure_modes（READ） |
| サマリー統計 | フィルタ条件（または全件） | COUNT(*), SUM(cost), AVG(downtime_hours) | KPIカード表示 | failure_reports（READ） |

## UI状態遷移

| 要素 | 対応機能 | 状態 | DB関連テーブル |
|------|---------|------|--------------|
| KPIカード群 | サマリー統計 | ローディング → 表示 → 更新中 | failure_reports（READ） |
| 円グラフ | 故障モード別内訳 | ローディング → 描画済み → 更新中 → 再描画 | failure_reports JOIN failure_modes（READ） |
| 折れ線グラフ | 月次トレンド | ローディング → 描画済み → 更新中 → 再描画 | failure_reports（READ） |
| 棒グラフ | コストTOP10 | ローディング → 描画済み → 更新中 → 再描画 | failure_reports（READ） |
| 示唆カード | 示唆出し | ローディング → 表示 → 更新中 | failure_reports, failure_modes（READ） |
| フィルターバー | フィルタリング | 初期値 → 選択中 → 適用済み | failure_modes（READ: 選択肢取得） |
