# 要件定義書 v2: データ入力画面

> DB設計を踏まえた要件定義書の更新

## 目的

現場保全担当者が自由記述の故障報告テキストを入力し、LLMによって構造化データ（JSON）に変換・確認・保存する画面。
故障報告の「入口」として、非構造化データを分析可能な構造化データに変換する役割を担う。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | テキスト入力 | 自由記述の故障報告テキストを入力する | DB関連テーブル: なし（UI操作のみ） |
| 2 | LLM構造化 | 入力テキストをLLM APIに送信し、構造化JSONを生成する | DB関連テーブル: failure_modes（故障モード名の照合） |
| 3 | 構造化結果表示 | LLMが抽出した構造化データを表示する | DB関連テーブル: なし（UI表示のみ） |
| 4 | 構造化結果の編集 | 構造化結果を人間が確認・修正できる | DB関連テーブル: failure_modes（故障モード選択肢の取得） |
| 5 | データ保存 | 確認済みの構造化データをDBに保存する | DB関連テーブル: failure_reports（INSERT）, failure_modes（参照/INSERT） |
| 6 | サンプルデータ投入 | デモ用のサンプル故障報告テキストを一括で投入し構造化する | DB関連テーブル: failure_reports（INSERT）, failure_modes（参照/INSERT） |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| テキスト入力 | ユーザーが入力する自由記述テキスト | テキストエリアに入力値を保持 | 入力済みテキスト | なし |
| LLM構造化 | 入力済み自由記述テキスト | LLM APIにテキストを送信、構造化項目を抽出。故障モードはfailure_modesマスタと照合 | 構造化JSON（発生日, 設備名, 現象, 原因, 対策, コスト, 停止時間, 故障モード） | failure_modes（READ: マスタ一覧をプロンプトに含める） |
| 構造化結果表示 | LLMから返却された構造化JSON | JSONをパースし、各項目をカード形式にレンダリング | カード表示 | なし |
| 構造化結果の編集 | ユーザーによる各項目の修正入力 | 編集フォームの値でJSONを更新。故障モードはドロップダウンで選択 | 修正済み構造化JSON | failure_modes（READ: ドロップダウン選択肢） |
| データ保存 | 確認済みの構造化JSON | failure_reportsにINSERT。故障モードが新規の場合はfailure_modesにもINSERT | 保存成功通知、フォームリセット | failure_reports（INSERT）, failure_modes（READ/INSERT） |
| サンプルデータ投入 | サンプルテキスト群（10〜20件） | 各テキストを順次LLM構造化→failure_reportsにINSERT | 投入完了通知、件数表示 | failure_reports（INSERT）, failure_modes（READ/INSERT） |

## UI状態遷移

| 要素 | 対応機能 | 状態 | DB関連テーブル |
|------|---------|------|--------------|
| テキストエリア | テキスト入力 | 空 → 入力中 → 入力済み → リセット | なし |
| 構造化ボタン | LLM構造化 | 無効 → 有効 → ローディング → 有効 | なし |
| ローディング表示 | LLM構造化 | 非表示 → 表示 → 非表示 | なし |
| 構造化結果カード | 構造化結果表示 | 非表示 → 表示 | なし |
| 編集フォーム（故障モード） | 構造化結果の編集 | ドロップダウン表示（failure_modesから選択肢取得） | failure_modes（READ） |
| 保存ボタン | データ保存 | 非表示 → 有効 → ローディング → 成功表示 | failure_reports（INSERT） |
| サンプル投入ボタン | サンプルデータ投入 | 有効 → ローディング → 完了表示 | failure_reports（INSERT） |
