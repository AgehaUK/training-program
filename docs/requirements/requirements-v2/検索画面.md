# 要件定義書 v2: 検索画面

> DB設計を踏まえた要件定義書の更新

## 目的

過去の故障事例をキーワードで検索し、類似事例の一覧を表示する画面。
現場保全担当者が故障発生時に迅速に過去事例を参照したり、設備設計者が特定部品の故障履歴を調査するために使用する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | キーワード検索 | 設備名・部品名・現象等のキーワードで故障事例を検索 | DB関連テーブル: failure_reports（LIKE検索）, failure_modes（JOIN） |
| 2 | 検索結果一覧表示 | 検索条件に合致する故障事例をリスト表示 | DB関連テーブル: failure_reports JOIN failure_modes |
| 3 | 詳細表示 | 選択した故障事例の全項目を表示 | DB関連テーブル: failure_reports JOIN failure_modes |
| 4 | 絞り込みフィルタ | 期間・故障モード・コスト範囲で絞り込む | DB関連テーブル: failure_reports, failure_modes |
| 5 | ソート | 発生日・コスト・停止時間で並び替え | DB関連テーブル: failure_reports（ORDER BY） |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| キーワード検索 | キーワード文字列 | failure_reports の equipment_name, symptom, cause, action_taken に対してLIKE検索。failure_modesをJOINして故障モード名を取得 | マッチした故障レコード一覧 | failure_reports（READ, LIKE）, failure_modes（READ, JOIN） |
| 検索結果一覧表示 | 検索結果レコード群 | テーブル行としてレンダリング（occurred_at, equipment_name, symptom, cause, cost, downtime_hours, failure_mode名） | テーブル表示、件数表示 | failure_reports, failure_modes（結果セットの表示） |
| 詳細表示 | 選択レコードのID | failure_reports.id でSELECT、failure_modesをJOIN | モーダルに全項目表示（original_text含む） | failure_reports（READ）, failure_modes（READ, JOIN） |
| 絞り込みフィルタ | 期間, 故障モードID, コスト範囲 | WHERE句にフィルタ条件追加。故障モード選択肢はfailure_modesから取得 | フィルタ適用後の検索結果 | failure_reports（READ）, failure_modes（READ） |
| ソート | ソートカラム, 方向 | ORDER BY句を適用（occurred_at, cost, downtime_hours） | ソート適用後の検索結果 | failure_reports（READ） |

## UI状態遷移

| 要素 | 対応機能 | 状態 | DB関連テーブル |
|------|---------|------|--------------|
| 検索ボックス | キーワード検索 | 空 → 入力中 → 入力済み | なし |
| 検索ボタン | キーワード検索 | 無効 → 有効 → ローディング → 有効 | failure_reports（READ） |
| 検索結果テーブル | 検索結果一覧 | 非表示 → ローディング → 結果表示 / 空結果表示 | failure_reports JOIN failure_modes（READ） |
| フィルターパネル | 絞り込みフィルタ | 折りたたみ → 展開 → 適用中 | failure_modes（READ: 選択肢） |
| ソートボタン群 | ソート | 未選択 → 昇順 → 降順 | failure_reports（READ） |
| 詳細モーダル | 詳細表示 | 非表示 → 表示 → 非表示 | failure_reports JOIN failure_modes（READ） |
| 件数表示 | 検索結果一覧 | 非表示 → 「N件」表示 | なし |
| ページネーション | 検索結果一覧 | 非表示 → 表示（複数ページ時） | failure_reports（READ） |
